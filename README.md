# Portfólio — Enzo Trotto

Site estático (HTML + CSS + JS puro), sem build. Pronto para deploy na Vercel.

## Rodar local
```bash
python -m http.server 8000
```
Abra http://localhost:8000

## Deploy na Vercel
Importe o repositório na Vercel. Framework preset: **Other**, sem build command, output na raiz.

## Editar
Os projetos ficam em `index.html`, na seção `#projetos` (um `<article class="card">` por projeto).
